# Explainers

Definition explainers live here as single HTML files with inline SVG. One concept per file. Name them after the question, not the answer: `cosine-similarity.html`, `what-is-infonce.html`.

Open one in a browser. No build step, no dependencies. Every diagram is inline SVG so the file works offline and survives being copied.

The tutor writes these when you ask "what is X" or "explain X". Debugging questions get hints instead.
use cdn for react and tailwind if needed or any other libs or fonts
